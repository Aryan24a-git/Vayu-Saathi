## A.1 What the Prototype Adds
The VayuSaathi prototype (`design/vayusaathi-prototype.html` / `VayuSaathi_-_Winter_Smog_AI_Copilot.html`) introduced:
1. **Header & Scenario Switcher:** 4 Winter smog scenarios (Delhi Severe, Patna Morning, Kolkata Smog, Winter Baseline) plus live Indian city geocoded search.
2. **CPCB NAQI Hero Card:** National Air Quality Index (NAQI 1–500), dominant pollutant identification (PM2.5, PM10, NO2), meteorological metrics (wind speed, temperature), Berkeley Earth cigarette equivalence (`PM2.5 / 22`), and health advice.
3. **24-Hour Inversion & Ventilation Curve:** Diurnal thermal inversion curve showing particulate buildup and dynamic safe cross-ventilation window (midday boundary layer mixing).
4. **Three Primary Tabs:**
   - **Playbook:** Personalized IAQ hacks, emission swaps, live impact meter, and interactive pledges.
   - **Copilot:** Multilingual chat (English, Hindi, Hinglish) and multimodal photo inspection for window gaps, kitchen exhaust, or mask seal fit.
   - **Community:** 1-Tap WhatsApp RWA Bulletin generator (English/Hindi), colony collective what-if simulator, and hyper-local smog pinboard with upvotes.
5. **60-Second Household Profile Drawer:** Health vulnerabilities, purifier availability, kitchen chimney/exhaust, commute mode/km, and budget tier.

## A.2 Conflicts and Gaps with Existing Spec, and Resolutions

| # | Prototype Behavior | Conflict / Violation | Resolution (Authoritative) |
|---|-------------------|----------------------|---------------------------|
| 1 | `GEMINI_API_KEY` in client JS; direct browser `fetch` to Google Generative AI | Violates SEC-002, SEC-003, SEC-012 (client credential exposure, no rate limits, no audit log) | All LLM calls move server-side (`src/server/llm/`). Browser never calls an LLM or holds an API key. |
| 2 | LLM invents arbitrary playbook items | Violates REQ-009, D6 (Catalog Grounding) | Rules engine selects catalog actions; Gemini only rewrites wording and explainers without changing action IDs or quantitative impacts. |
| 3 | CPCB NAQI (India standard), not US EPA AQI | Supersedes initial Assumption A1 | Primary standard becomes CPCB NAQI with PM2.5, PM10, and NO2 sub-indices. US AQI retained only as optional legacy configuration. |
| 4 | Stations labelled 'CPCB' with instant station names (e.g. Anand Vihar) | Open-Meteo values are gridded model/satellite assimilation, not direct continuous CPCB sensor feeds | Label data as "Model-derived NAQI equivalent (Open-Meteo)", never fabricate real-time CPCB telemetry. |
| 5 | Static / past ventilation window (e.g. 11 AM - 1 PM) shown even at 8 PM | Recommending past actions violates D3 (Do No Harm) | Compute ventilation window for remaining daytime hours today (10 AM - 3 PM); if after 4 PM, project tomorrow's window and label as heuristic. |
| 6 | Multimodal photo upload with unvalidated base64 string | Security risk: memory exhaustion, malicious file upload, SSRF | Server validates magic bytes (JPEG/PNG/WebP), caps payload at 256 kB (client-side resize to ≤1024px), never persists to disk or database (SEC-011). |
| 7 | Invented colony counters (e.g. "2,840 families active") | Misleading metrics without persistence violate truth-in-data | Show device-local pledges; collective simulator displays transparent "What-if" mathematical projection clearly badged as an estimate. |
| 8 | Fixed cigarette factor (PM2.5 / 22) presented without methodology | Sourced impact requirement D4 | Attribute explicitly to Berkeley Earth methodology (1 cigarette ≈ 22 µg/m³ PM2.5 over 24 hours), labelled as rough indicator. |
| 9 | Anthropic Claude SDK configured in earlier spec | Provider proliferation & redundant dependency | Adopt Gemini as single GenAI provider across text, structured narration, and multimodal vision (ADR-004). |
| 10 | Unconstrained free-form RWA text input | Injection risk via WhatsApp copy/share links | Strict length caps, character sanitization, and URL encoding (`encodeURIComponent`) for `wa.me` links. |
| 11 | Hotspot pinboard stored without privacy boundaries | Potential PII collection on server | Hotspots stored exclusively in client `localStorage`; zero server persistence; labelled "Device-local pinboard". |
| 12 | Prototype used Tailwind CDN and external Chart.js CDN | Violates CSP and offline bundle reliability (PERF-001) | Self-hosted pure SVG rendering in React; zero external runtime CDNs. |
| 13 | Profile schema v1 used generic fields; prototype uses v2 fields | Incompatible profile state | Implement formal Profile Schema v2 with automated v1-to-v2 migration and backward-compatible defaults. |
| 14 | Hindi text rendered without language tags | Screen readers mispronounce Hindi text (A11Y-007) | Enforce `lang="hi"` on all Hindi/Hinglish copy blocks and bulletin previews. |

## Migration and Compatibility Risks
1. **Profile Schema v1 to v2:** Users with stored v1 profiles will be upgraded seamlessly via `migrateProfileV1ToV2()`; unknown fields discarded, missing fields assigned safe defaults (`budgetTier: 'zero_cost'`, `purifier: 'none'`).
2. **Provider Switch (Anthropic -> Gemini):** All references to `@anthropic-ai/sdk` removed. `LlmClient` interface preserved with `GeminiClient` implementing identical method signatures.
3. **Data Integrity:** Any synthetic demo data must carry the badge `Demo scenario (synthetic data)` to eliminate user confusion regarding real-time sensor veracity.
